## 👋 Welcome

Hey there! We're **Amaze Continuity Projects** — a community of developers building open-source tools to improve student life at **VIT University**.

Our flagship project is **[AmazeCC](https://amazecc.com)**, a modern student dashboard that replaces the clunky VTOP portal with a fast, intuitive, and feature-rich experience.

---

## 📦 Our Projects

| Project | Description | Stack |
|---------|-------------|-------|
| [AmazeCC](https://github.com/AmazeContinuityProjects/AmazeCC) | Main student dashboard — attendance, grades, timetable, hostel, events & more | Next.js, TypeScript, Tailwind |
| [AmazeCC-Dashboard](https://github.com/AmazeContinuityProjects/AmazeCC-Dashboard) | Dashboard for AmazeCC apps | Next.js, TypeScript |
| [amazecc-api](https://github.com/AmazeContinuityProjects/amazecc-api) | Backend API — scrapes VTOP, serves data to all AmazeCC apps | Next.js, TypeScript |
| [AmazeCC-CLI](https://github.com/AmazeContinuityProjects/AmazeCC-CLI) | Native CLI tool — check grades & attendance from terminal | Go |
| [AmazeCC-Native](https://github.com/AmazeContinuityProjects/AmazeCC-Native) | Native mobile app for Android & iOS (coming soon) | React Native |
| [AmazeCC-Club-Hub](https://github.com/AmazeContinuityProjects/AmazeCC-Club-Hub) | Club management platform for campus communities | Next.js, TypeScript |
| [AmazeSort](https://github.com/AmazeContinuityProjects/AmazeSort) | AI-powered file sorting application | Python, PySide6 |
