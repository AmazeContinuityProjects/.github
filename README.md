## About

Amaze Continuity Projects is a GitHub organization dedicated to creating and maintaining open-source tools that enhance the student experience at VIT University. Our flagship project is **AmazeCC**, a comprehensive student dashboard that replaces the official VTOP portal.

---

## Repositories

| Repository | Description | Language |
|------------|-------------|----------|
